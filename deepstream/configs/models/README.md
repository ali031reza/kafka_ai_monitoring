# Model configuration files

Store version-controlled model configuration and label files here when
required by the selected DeepStream release and inference plugin.

Keep model binaries and TensorRT engines in deepstream/models/ instead.
The exact configuration format will be selected after Phase 0 confirms the
DeepStream release and Phase 2 validates the first real model.

Do not add release-specific nvinfer or Service Maker configuration files
until their required fields have been checked against the selected NVIDIA
documentation and model.
